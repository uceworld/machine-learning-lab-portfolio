# Machine Learning Lab Portfolio

A developing collection of reproducible machine-learning experiments, technical notebooks and evaluation studies.

**Author:** Uchenna Echem Okorie  
**Academic context:** MSc Computer Science and Technology, Wenzhou University.

## Scope
- Regression and classification baselines
- Decision trees and ensemble learning
- K-nearest neighbors, support vector machines and neural networks
- Principal component analysis and unsupervised clustering
- An independent end-to-end machine-learning project

## Status
Repository infrastructure is being prepared. Validated experiments will be added when completed and cleared for publication. No experimental performance claims are made at this stage.

## Research standards
Each published study should document its research question, dataset source, preprocessing, validation protocol, reproducible commands, quantitative results and limitations.

See [Methodology](docs/methodology.md) and [Reproducibility](docs/reproducibility.md).
